# 太鼓譜面メーカー

音声ファイルから「太鼓の達人」風の譜面（ドン・カッ）を自動生成し、エディタで手直しして
[TJA 形式](https://github.com/0auBSQ/OpenTaiko)（TJAPlayer / OpenTaiko などで遊べる形式）で書き出せるブラウザアプリです。
サーバー側の処理はなく、音声はブラウザの外に送信されません。

## 起動方法

ES Modules と Web Worker を使うため、`file://` で直接開くのではなく簡易サーバー経由で開いてください。

```sh
npm start            # http://localhost:8080/ （依存パッケージなし）
# または
python3 -m http.server 8080
```

## 使い方

1. **音声を読み込んで自動生成** — 音声ファイルをドロップし、難易度プリセットを選んで「自動で譜面を作る」。
   BPM・小節頭（オフセット）・音符を推定して下書きを作ります。
   - BPM が倍/半分になっている場合は「BPM×2 / ÷2」や候補ボタンで直せます。
   - BPM が分かっている場合は「BPM 指定」に入れると精度が上がります。
   - 感度・グリッド・最小間隔・ドンの割合・大音符の割合を変えて「現在の BPM/オフセットで作り直す」と、
     解析をやり直さずに即座に作り直せます。
2. **譜面を編集** — タイムライン上でクリックして音符を置く／消す、範囲選択して移動・コピー・ドンカッ反転など。
   再生しながら `F`/`J`（ドン）・`D`/`K`（カッ）を叩いて打ち込む「リアルタイム入力」もできます。
   波形の上の赤/青の目盛りは自動検出した音（赤=低い音、青=高い音）で、手修正の目安になります。
3. **曲情報と書き出し** — タイトルなどを入力して「TJA を書き出す」。音源ファイルと同じフォルダに置けば遊べます。
   既存の TJA の読み込み（UTF-8 / Shift_JIS）や、プロジェクトの JSON 保存にも対応しています。
   編集中の譜面はブラウザに自動保存されます（音声は保存されないので再度読み込んでください）。

操作方法の詳細はアプリ画面下部の「操作方法」を参照してください。

## 自動生成のしくみ

機械学習モデルではなく、信号処理によるヒューリスティクスです（`js/analysis.js`）。

1. STFT（約 10ms 間隔）で低域（30–250Hz）・中域・高域（2–12kHz）ごとのスペクトルフラックスを計算
2. 立ち上がり（オンセット）をピーク検出
3. 自己相関で BPM 候補を出し、曲全体で位相が最もよく揃う値に精密化。倍/半分の曖昧さは
   「拍頭と裏拍の強さの差」と「16分グリッドへの乗り具合」で判定
4. 低域の強い音が集まる位置を小節頭としてオフセットを決定
5. オンセットをグリッドに量子化し、低域寄りの音をドン・高域寄りの音をカッ、強い音を大音符に割り当て

太鼓の譜面は「音をすべて拾う」ものではなく作り手の解釈が入るものなので、自動生成はあくまで下書きです。
エディタでの仕上げを前提にしています。

## 制限事項

- 曲中の BPM 変化（`#BPMCHANGE`）・拍子変更の書き出し、譜面分岐、風船音符には未対応です
  （読み込み時は `#MEASURE` のみタイミングに反映し、その他は無視して警告を表示します）。
- 書き出しは 4/4 拍子・単一 BPM です。

## 開発

```sh
npm test   # 解析（合成ドラム音源での BPM/オフセット/音符の復元）と TJA 入出力のテスト
```

| ファイル | 役割 |
| --- | --- |
| `js/analysis.js` | 音声解析・自動譜面生成（DOM 非依存、Node でもテスト可能） |
| `js/chart.js` | 譜面データモデル、TJA 書き出し/読み込み |
| `js/editor.js` | Canvas の譜面エディタ |
| `js/player.js` | 再生、ヒット音・メトロノーム、波形データ |
| `js/store.js` | 譜面の状態と元に戻す/やり直す |
| `js/main.js` | UI の組み立て |
